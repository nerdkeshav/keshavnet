# Keshav Network

Library of my projects (te-he) plus a Next.js 15 app with Tailwind CSS, Radix UI components, and TypeScript.

## Development

Install dependencies (pnpm recommended):

```
pnpm install
```

Run the dev server:

```
pnpm run dev
```

Open http://localhost:3000.

## Build for production

```
pnpm run build
pnpm start
```

## Lint

```
pnpm run lint
```

## Tech Stack
- Next.js 15
- React 19
- Tailwind CSS 3
- Radix UI
- TypeScript 5

## Environment Variables
Create an `.env.local` file for any required secrets (none required yet). Example template:

```
# .env.example
# API_KEY=your_key_here
```
